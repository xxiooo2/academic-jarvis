# Academic J.A.R.V.I.S 사용 안내

## 안드로이드에서 시작하기

안드로이드 Chrome에 설치할 때는 [안드로이드 설치 안내](안드로이드%20설치%20안내.md)를 참고하세요. HTTPS로 앱을 호스팅한 후 Chrome 메뉴에서 홈 화면에 설치하면 됩니다.

## PC 브라우저에서 시작하기

1. `start-app.ps1`을 실행하고 브라우저가 열릴 때까지 기다립니다.
2. 열린 창은 앱을 쓰는 동안 켜 둡니다. 앱을 마치면 이 창에서 `Ctrl+C`를 눌러 종료합니다.
3. 화면 오른쪽 위 학생 설정에서 이름과 학년·반을 입력합니다.

## 지금 작동하는 기능

- 할 일 추가, 완료 표시, 삭제, 브라우저에 자동 저장
- 수행평가 마감일 등록과 남은 분량의 일별 할 일 배분
- 25분 집중 타이머와 과목별 공부 시간 기록
- 이번 주 공부 기록과 과목별 시간 리포트
- 평가 비율을 반영한 목표 점수 계산
- Gemini 학습 질문 및 문제 사진 풀이
- 경복고 급식 조회 연결과 시간표 이미지 보관
- 학습 데이터 JSON 백업 및 복구

## AI 답변 연결

AI 학습 도우미 화면에서 Google AI Studio에서 발급한 Gemini API 키를 입력하세요. 키는 브라우저 세션이 끝날 때까지 현재 기기에만 보관됩니다. 질문과 첨부한 문제 사진은 답변 생성을 위해 Google Gemini API에 전달됩니다. 키 발급 및 사용에는 Google 계정과 API 이용 조건이 적용됩니다.

## 경복고 급식 연결

NEIS 교육정보 개방 포털에서 API 인증키를 신청한 뒤, 시간표·학교 정보 화면의 NEIS 인증키 칸에 넣고 급식을 불러오세요. 경복고는 서울교육청 코드 `B10`, 학교 코드 `7010062`로 설정했습니다. NEIS에 당일 메뉴가 등록되지 않았거나 인증키가 유효하지 않으면 안내 메시지가 표시됩니다.

## 저장과 시간표

계획, 성적 입력값 외 학생 학습 기록은 현재 브라우저의 로컬 저장소에 보관됩니다. 앱을 다른 브라우저나 기기에서 열면 자동으로 공유되지 않으므로 설정에서 JSON 백업을 내려받아 보관할 수 있습니다. 시간표 이미지는 브라우저 내부 저장소에 보관됩니다. 시간표 사진을 보내주시면 실제 과목·교시로 대시보드를 채우겠습니다.
