# 안드로이드에서 설치하기

앱은 Android Chrome에서 설치하는 PWA 형식으로 준비했습니다. 설치하면 브라우저 주소창 없이 홈 화면 아이콘으로 실행할 수 있고, 기본 화면은 오프라인에서도 열립니다.

## 설치 순서

1. `outputs` 폴더 안 파일 전체를 HTTPS를 지원하는 정적 웹 호스팅에 올립니다. 폴더 안의 `index.html`, `manifest.webmanifest`, `service-worker.js`, `icon-192.png`, `icon-512.png`, `icon.svg`가 같은 위치에 있어야 합니다.
2. Android Chrome에서 업로드한 HTTPS 주소를 엽니다.
3. 우측 상단 메뉴에서 **앱 설치** 또는 **홈 화면에 추가**를 선택합니다. 앱 설정 화면에도 설치 버튼이 있습니다.
4. 홈 화면의 JARVIS 아이콘을 눌러 실행합니다.

이 대화에서는 사용자의 호스팅 계정에 로그인하거나 공개 주소를 만들 수 없어, 아직 설치 링크를 발급하지 않았습니다. HTTPS 주소에 올린 뒤에만 PWA 설치와 카메라·파일 선택, 외부 API 호출이 작동합니다.

## AI와 학교 급식

AI 학습 도우미에서 Gemini API 키를 입력하면 텍스트 질문과 카메라로 찍은 문제 사진을 보낼 수 있습니다. NEIS 인증키는 시간표·학교 정보 화면에서 입력합니다. 키는 브라우저 세션에 보관되며, 질문·사진은 Gemini로, 급식 조회는 NEIS로 전송됩니다. 개인용 앱으로만 사용하고 키를 공개 저장소에 올리지 마세요.

## 데이터 보관

학습 기록은 앱을 설치한 Android 브라우저의 로컬 저장소에 저장됩니다. 브라우저 데이터 삭제나 앱 저장 공간 초기화 전에 설정에서 JSON 백업을 내려받으세요. 서버 계정 동기화는 아직 구현하지 않았습니다.
